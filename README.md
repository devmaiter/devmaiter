## Hi, I'm Julián 👋

I build tools where **networking meets live audio/video**: network diagnostics, protocols, metadata, and automation.

- 🔭 **Now:** [NetQuick](https://github.com/devmaiter/NetQuick) — a Python network diagnostics toolkit (v1.1.0)
- 🌱 **Open source:** PRs to [terraform-provider-minio](https://github.com/aminueza/terraform-provider-minio/pulls/devmaiter) and experiments with [exif-py](https://github.com/devmaiter/exif-py)
- 🎛️ **Into:** networked audio (Dante / NMOS), DMX lighting control, image metadata forensics
- 📫 **Contact:** open an issue or find me around here
