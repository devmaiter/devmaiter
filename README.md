## Hola, soy Julián 👋

Construyo herramientas donde se cruzan **las redes y el audio/video en vivo**: diagnóstico de red, protocolos, metadatos y automatización.

- 🔭 **Ahora:** [NetQuick](https://github.com/devmaiter/NetQuick) — toolkit de diagnóstico de red en Python (v1.1.0)
- 🌱 **Open source:** PRs en [terraform-provider-minio](https://github.com/aminueza/terraform-provider-minio/pulls/devmaiter) y experimentos con [exif-py](https://github.com/devmaiter/exif-py)
- 🎛️ **Me interesan:** audio en red (Dante / NMOS), control de iluminación DMX, forense de metadatos de imágenes
- 📫 **Contacto:** abre un issue o encuéntrame por aquí
